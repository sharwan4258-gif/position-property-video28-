# CSS Position Property Practice

This repository contains my personal practice code and hands-on exercises for mastering the **CSS `position` property**, built while following **CodeWithHarry's Web Development Playlist** (Video #28).

## 🚀 Overview
This project demonstrates how element positioning works in CSS, covering the primary positioning schemes:
* **`static`**: Default layout positioning according to the normal document flow.
* **`relative`**: Positioned relative to its normal position without affecting layout flow.
* **`absolute`**: Positioned relative to its nearest non-static ancestor element.
* **`fixed`**: Positioned relative to the browser window/viewport.
* **`sticky`**: Dynamic positioning that switches between relative and fixed based on user scroll position.
